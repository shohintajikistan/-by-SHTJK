📄 Соглашение

1. Назначение приложения

SHTJK предоставляет информационный сервис для просмотра курсов обмена валют банков Таджикистана.

2. Информация о курсах

Курсы валют могут изменяться. Информация предоставляется исключительно в ознакомительных целях.

3. Ответственность

Пользователям следует уточнять актуальный курс непосредственно в соответствующем банке перед совершением финансовых операций.

4. Изменение условий

Соглашение может обновляться по мере развития приложения.
